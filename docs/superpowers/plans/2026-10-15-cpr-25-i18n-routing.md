# CPR-25 — I18n Routing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for the preserved Native method. Steps use checkbox (`- [ ]`) syntax for tracking. Use superpowers:subagent-driven-development only if Founder explicitly changes the method.

**Goal:** URL publik dan shell Compro berfungsi dalam ID/EN dengan locale yang benar, serta kontrak slug siap dipakai fitur konten dan tombol switch CPR-34.

**Architecture:** next-intl menjadi satu sumber mapping pathname dan navigasi. Root layout publik berlocale dipisahkan dari root layout admin Indonesia; proxy hanya menangani negosiasi/redirect publik. Resolver slug merupakan fungsi murni atas referensi terjemahan terbit, tanpa tabel atau konten publik fiktif.

**Tech Stack:** Node 24.21.0, Next.js 16.4.0, next-intl 4.14.9, React 19.2.6, TypeScript strict, Vitest 4.1.11. Tidak menambah dependency produk.

**Spec:** [Rancangan CPR-25 yang disetujui](../specs/2026-10-15-cpr-25-i18n-routing-design.md), PRD §6/§9.4/§10 dan [CPR-34](https://linear.app/sineva-tech/issue/CPR-34/i18n-tombol-pindah-bahasa-ke-halaman-padanan).

**Status:** Spec disetujui, termasuk penajaman scope persistence. Plan menunggu review; kode aplikasi belum berubah. Metode Native dipertahankan. Branch CPR-25 berasal dari main `0156c0e997db79558adba11d874e17a75b7b0c6b`, dengan baseline 77 unit lulus. ## Global Constraints

- Bahasa hanya `id` dan `en`, default `id`, dengan prefix selalu terlihat.
- Kunjungan `/`: cookie `NEXT_LOCALE` yang valid → negosiasi `Accept-Language` → `id`. URL dengan prefix valid menentukan bahasa, meskipun cookie/browser berbeda.
- Tidak menggabungkan kamus Indonesia sebagai fallback Inggris. Nama brand tidak diterjemahkan.
- `/admin`, `/api`, internal Next dan aset tidak diprefix atau dialihkan oleh i18n. Admin tetap Indonesia.
- Cookie pilihan bahasa menggunakan path `/`, SameSite Lax dan Secure di production; terpisah dari cookie autentikasi.
- Konten bisnis tetap di PostgreSQL per `(entity_id, locale)`. Pemetaan slug memakai identitas entitas dan locale tujuan, bukan menerjemahkan/mengganti string slug secara otomatis.
- CPR-25 membuat rute/shell dan kontrak resolver; schema/constraint/query database riil mengikuti tiket konten. Detail tanpa data terbit → 404. Tidak membuat konten fiktif atau tabel konten generik.
- Tombol ID/EN, integrasi header dan penyimpanan pilihan melalui interaksi tombol tetap CPR-34. Kontrak fallback artikel satu bahasa ke daftar blog tujuan disiapkan di sini.
- UI mengikuti desain sementara dan logo yang ada; desain final menunggu instruksi Founder. Admin custom/Better Auth dipertahankan.
- Tidak mengaktifkan CI, memakai layanan berbayar, menambah CRUD konten atau mengerjakan SEO lengkap. Tidak membawa file/commit CPR-10.
- Verifikasi lokal; tidak merge/deploy tanpa instruksi Founder. Fixtures database dibersihkan hanya berdasarkan ID milik tes, tanpa menyentuh DB developer.

## Review Focus

1. URL EN dengan cookie ID, header malformed/q=0 dan cookie tidak valid: URL eksplisit menang; deteksi root tidak crash atau memilih English yang dilarang. Tests Task 1–2.
2. Redirect root personal dibagi cache, query string hilang, atau alias membentuk loop: respons tidak di-cache bersama, query tetap, URL final benar. HTTP Task 2.
3. Path admin/API/aset atau header locale palsu: tidak berubah ke route publik, admin tetap ID dan guard auth tetap berlaku. HTTP Task 2–3.
4. Kamus EN hilang key atau root layout/metadata memuat teks ID: fail dalam tes, tidak memakai fallback Indonesia atau mengirim kedua kamus ke client. Unit/HTTP Task 2.
5. Slug berbeda, ID sama lintas jenis, target draft/hilang/duplikat: tidak membuka entitas/locale yang salah; fallback daftar hanya untuk blog. Unit Task 1; handoff data nyata didokumentasikan Task 3.

## Task 1: Registry rute dan kontrak slug publik yang teruji

**Files:** routing/navigation/content-links dan dua unit tests pemilik pada tabel.

**Produces:**

```ts
export type Locale = 'id' | 'en'
export type ContentKind = 'service' | 'portfolio' | 'post'
export type TranslationReference = Readonly<{
  kind: ContentKind
  entityId: string
  locale: Locale
  slug: string
  published: boolean
}>
export type ContentTarget =
  | Readonly<{ status: 'detail'; href: string }>
  | Readonly<{ status: 'list'; href: string }>
  | Readonly<{ status: 'unavailable' }>
export function resolveTranslatedHref(
  input: Readonly<{ kind: ContentKind; entityId: string; targetLocale: Locale }>,
  translations: readonly TranslationReference[],
): ContentTarget
```

Resolver hanya menerima referensi metadata internal, tidak membaca DB, cookie atau request. Tidak dipanggil oleh shell detail untuk mempublikasikan fixture. Query fitur konten nantinya menyediakan referensi yang berizin/terbit dan constraint database sendiri.

- [ ] **Step 1 — RED mapping dan resolver.** Tulis tes mapping seluruh pasangan tabel PRD, termasuk AI & Otomasi, produk dan terima kasih. Ekspektasi ditulis sebagai URL literal, bukan dibangun dari registry yang sedang diuji. Contoh:

```ts
expect(getPathname({ locale: 'id', href: '/services/ai-automation' })).toBe(
  '/id/layanan/ai-otomasi',
)
expect(getPathname({ locale: 'en', href: '/contact/thank-you' })).toBe('/en/contact/thank-you')
expect(
  resolveTranslatedHref({ kind: 'post', entityId: 'post-1', targetLocale: 'en' }, [
    { kind: 'post', entityId: 'post-1', locale: 'id', slug: 'panduan-ai', published: true },
    { kind: 'post', entityId: 'post-1', locale: 'en', slug: 'ai-guide', published: true },
  ]),
).toEqual({ status: 'detail', href: '/en/blog/ai-guide' })
```

Kasus tambahan: target post hilang/draft → `/en/blog`; service/portfolio hilang/draft → unavailable; entitas lain/jenis lain dengan ID sama tidak cocok; target locale salah tidak dipakai; dua referensi target yang bentrok → unavailable, bukan pilih pertama. Slug kosong, slash/backslash, `.`/`..`, URL absolut dan encoded traversal ditolak menjadi unavailable; slug domain v1 memakai lowercase Latin/digit dengan separator `-`. Jalankan `npm test -- tests/unit/i18n-routing.test.ts tests/unit/i18n-content-links.test.ts`; harus RED karena modul/behavior belum ada.

- [ ] **Step 2 — implementasi minimal registry.** Pakai API library yang sudah terpasang:

```ts
export const routing = defineRouting({
  locales: ['id', 'en'],
  defaultLocale: 'id',
  localePrefix: 'always',
  localeDetection: true,
  alternateLinks: false,
  localeCookie: {
    name: 'NEXT_LOCALE',
    path: '/',
    sameSite: 'lax',
    secure: process.env.NODE_ENV === 'production',
    maxAge: 31_536_000,
  },
  pathnames: {
    '/': '/',
    '/services': { id: '/layanan', en: '/services' },
    '/services/web-development': {
      id: '/layanan/web-development',
      en: '/services/web-development',
    },
    '/services/ai-automation': { id: '/layanan/ai-otomasi', en: '/services/ai-automation' },
    '/services/[slug]': { id: '/layanan/[slug]', en: '/services/[slug]' },
    '/portfolio': { id: '/portofolio', en: '/portfolio' },
    '/portfolio/[slug]': { id: '/portofolio/[slug]', en: '/portfolio/[slug]' },
    '/products/chatbot': { id: '/produk/chatbot', en: '/products/chatbot' },
    '/blog': '/blog',
    '/blog/[slug]': '/blog/[slug]',
    '/about': { id: '/tentang-kami', en: '/about' },
    '/contact': { id: '/kontak', en: '/contact' },
    '/contact/thank-you': { id: '/kontak/terima-kasih', en: '/contact/thank-you' },
    '/privacy-policy': { id: '/kebijakan-privasi', en: '/privacy-policy' },
  },
})
export const { Link, redirect, getPathname, usePathname, useRouter } = createNavigation(routing)
```

Tempatkan defineRouting dan export navigation di file pemilik terpisah. Matikan alternateLinks otomatis sampai data/hreflang ditangani CPR-52; jangan mengiklankan padanan slug yang belum ada. Resolver memfilter kind/entityId/locale/published, memvalidasi slug dengan `/^[a-z0-9]+(?:-[a-z0-9]+)*$/`, dan membangun URL melalui getPathname dengan param slug. Tidak menebak terjemahan dari URL sumber.

- [ ] **Step 3 — GREEN dan commit.** Jalankan targeted tests lalu seluruh `npm test`; semua kasus termasuk Review Focus 5 harus lulus. `npx tsc --noEmit`/lint/format sesuai source yang disentuh. Commit `feat(i18n): define localized routes and content link contract (CPR-25)`.

## Task 2: Integrasi proxy, layout dan shell ID/EN tanpa mengubah admin

**Files:** request/types/proxy/config/messages/layout/page-shell, seluruh page di bawah dan unit/integration tests pemilik.

**Consumes:** `routing`, navigation dan `Locale` Task 1. **Produces:** HTTP root redirect, shell locale, dan 404 yang benar; tidak ada tombol switch/DB konten baru.

Rute fisik di bawah `src/app/(public)/[locale]/`: `page.tsx`, `services/page.tsx`, `services/web-development/page.tsx`, `services/ai-automation/page.tsx`, `services/[slug]/page.tsx`, `portfolio/page.tsx`, `portfolio/[slug]/page.tsx`, `products/chatbot/page.tsx`, `blog/page.tsx`, `blog/[slug]/page.tsx`, `about/page.tsx`, `contact/page.tsx`, `contact/thank-you/page.tsx`, `privacy-policy/page.tsx`. Detail dinamis umum memanggil notFound sampai query domain tersedia; dua layanan bernama di PRD adalah shell statis yang dikenal.

- [ ] **Step 1 — RED HTTP dan kamus.** Tambahkan tes key parity rekursif kamus ID/EN (termasuk value string nonempty), serta HTTP manual redirect dan HTML. Contoh hasil independen:

```ts
const root = await fetch(new URL('/?utm_source=test', base), {
  redirect: 'manual',
  headers: { cookie: 'NEXT_LOCALE=id', 'accept-language': 'en-US' },
})
expect(root.status).toBe(307)
expect(new URL(root.headers.get('location')!, base).pathname).toBe('/id')
expect(new URL(root.headers.get('location')!, base).search).toBe('?utm_source=test')
const english = await fetch(new URL('/en/about', base), {
  headers: { cookie: 'NEXT_LOCALE=id', 'accept-language': 'id' },
})
const html = await english.text()
expect(english.status).toBe(200)
expect(html).toContain('lang="en"')
expect(html).toContain('About us')
expect(html).not.toContain('Tentang kami')
```

Matrix root: cookie en + header id → en; cookie invalid + en-GB → en; id;q=0.9,en;q=0.1 → id; en;q=0 → id; tanpa header/cookie, header tidak cocok/malformed → id. Pastikan response personal `Cache-Control: private, no-store` dan Vary Cookie/Accept-Language; follow redirect terukur tidak berulang. Uji semua shell PRD di ID/EN, query pada canonical redirect, unknown locale/slug/draft fixture tidak mendapat body detail. Jalankan pada server baseline yang tervalidasi: tes baru harus RED karena redirect/rute belum ada. Jangan melemahkan test root lama agar belum ada implementasi terlihat hijau.

- [ ] **Step 2 — wire next-intl dan root layouts.** Baca panduan Next terpasang internationalization, layout, proxy, not-found dan next-root-params. Bungkus config dengan `createNextIntlPlugin('./src/i18n/request.ts')`; gunakan API next/root-params untuk locale root publik, sesuai dokumentasi dan typegen, bukan mengambil cookie di render halaman eksplisit. Root publik menghasilkan tepat satu html/body dengan locale valid; root admin tepat satu html/body `lang=id`, import globals pada kedua root. Metadata dasar root tidak boleh memuat deskripsi ID di halaman EN. Jangan memasang provider publik pada admin/API atau mengubah guard Better Auth. Navigasi lintas root memuat halaman penuh, sesuai perilaku Next.

```ts
// request.ts: hanya dipanggil jalur render publik yang berlocale
import * as rootParams from 'next/root-params'
import { getRequestConfig } from 'next-intl/server'
import { hasLocale } from 'next-intl'
import { notFound } from 'next/navigation'
import { routing } from './routing'

export default getRequestConfig(async () => {
  const locale = await rootParams.locale()
  if (!hasLocale(routing.locales, locale)) notFound()
  return { locale, messages: (await import(`../../messages/${locale}.json`)).default }
})
```

Validasi locale sebelum memilih import. Global AppConfig types mengacu pada `Locale` dan bentuk kamus ID; parity test menegakkan kamus EN lengkap. onError mencatat kategori tetap tanpa raw Error. getMessageFallback mengembalikan pesan dalam locale aktif (`Konten belum tersedia.` / `Content unavailable.`), bukan key internal/stack atau pesan dari kamus lain. Parity test menggagalkan perubahan yang kehilangan key sebelum dipublikasikan.

- [ ] **Step 3 — proxy dan 404.** `src/proxy.ts` memanggil `createMiddleware(routing)` hanya untuk URL publik. Matcher mengecualikan batas segmen `/admin`, `/api`, `/_next` dan `/brand` (direktori aset repo saat ini). Gunakan batas segmen, bukan pola yang juga mengecualikan `/administrator` atau seluruh pathname bertitik. Aset baru mengikuti daftar prefix yang eksplisit; path detail bertitik tetap melewati validasi route. Prefix valid tetap diproses agar request-locale internal ditetapkan dari URL dan header palsu ditimpa. Untuk root, normalisasi header Accept-Language malformed agar tidak crash; pakai negosiasi library untuk header valid. Tambahkan Cache-Control private/no-store dan gabungkan Vary tanpa menghapus header library pada redirect personal. Path tidak dikenal/catch-all memanggil notFound; jangan memakai redirect sebagai pengganti 404. Pakai not-found locale dan fallback bawaan Next; jangan mengaktifkan flag experimental hanya untuk kosmetik 404. Build dan uji unknown routes wajib membuktikan kombinasi root layouts ini valid.

- [ ] **Step 4 — shell dan pesan.** `PublicPageShell({page}: {page: PublicPageKey})` membaca namespace `Pages`, menampilkan brand, judul sesuai page, dan pesan ID `Halaman sedang disiapkan.` / EN `This page is being prepared.`. `PublicPageKey` union: `home | services | webDevelopment | aiAutomation | portfolio | chatbot | blog | about | contact | thankYou | privacy`. Tiap page statis hanya memilih key miliknya; contoh:

```tsx
export default function AboutPage() {
  return <PublicPageShell page="about" />
}
```

Kamus menggunakan key yang sama dan judul terjemahan yang lengkap. Public 404 ID `Halaman tidak ditemukan.` / EN `Page not found.`; tidak memuat kedua kamus ke client. Shell belum berisi form kontak, artikel buatan, kebijakan hukum fiktif, header final atau tombol switch. Metadata shell ditandai noindex selama konten belum siap; hreflang/OG/sitemap lengkap tetap tiket SEO.

- [ ] **Step 5 — GREEN, regresi dan commit.** Sesuaikan foundation HTTP test untuk root redirect baru dan home locale. Jalankan unit, lint/typecheck/format/build, lalu HTTP integration di server production tervalidasi.
