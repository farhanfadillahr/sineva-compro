# CPR-23 Media Implementation Plan

> **For agentic workers:** gunakan superpowers:executing-plans; Founder memilih satu agen Native, tanpa reviewer/subagent tambahan. PR tiket menuju development dan langsung merge setelah verifikasi.

**Goal:** media library custom dengan file SeaweedFS, metadata/alt PostgreSQL dan lifecycle publish yang aman.

**Architecture:** adapter MediaStore terpisah dari service yang mengatur transaksi, otorisasi dan audit. Upload dibatasi pada route server. Delivery publik memakai record immutable yang hanya muncul sesudah commit publish.

**Tech Stack:** Next.js 16, React 19, Better Auth, Drizzle/PostgreSQL, AWS SDK v3, Sharp 0.35.5, kit admin CPR-80.

**Spec:** `docs/superpowers/specs/2026-10-16-cpr-23-media-design.md`.

## Global constraints

- Satu agen; branch `farhan/cpr-23-media`; base dan merge PR ke development.
- Main static tidak dipromosikan atau diganti; VPS/CDN production belum disiapkan.
- Image 10 MiB/6000 px; video 20 MiB; PDF 10 MiB; SVG ditolak; secret server-only.
- Locale aktif dari registry routing; copy validator sama; metadata/audit satu transaksi.

## Review focus

- Byte aktual melewati batas meski Content-Length palsu: hentikan stream dan jangan tulis file.
- Role/sesi dicabut setelah pemeriksaan awal: tolak saat transaksi, bersihkan object baru.
- Publish callback atau audit gagal sesudah copy: rollback metadata/usage dan cleanup hanya key baru.
- Replace/publish/delete bersamaan: kunci owner serta media secara konsisten; jangan rusak URL publik versi sebelumnya.
- Purge demo saat record telah diedit/dipakai operator: pertahankan data nyata, jangan hapus binary remote.
